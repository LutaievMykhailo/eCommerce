# E-commerce Web Application

A responsive e-commerce frontend built with React, TypeScript and Tailwind CSS.

The project focuses on building a modern shopping experience with product browsing, search, filtering, sorting and shopping cart functionality.

## 🔗 Live Demo

https://e-commerce-eosin-omega-46.vercel.app/

## ✨ Features

* Product catalog
* Product search
* Category and brand filtering
* Price, rating and stock filters
* Product sorting
* Product details page
* Related products
* Shopping cart
* Cart quantity management
* Responsive design
* Loading states
* Error handling with retry
* Empty states
* REST API integration

## 🛠 Tech Stack

* React
* TypeScript
* React Router
* Context API
* Tailwind CSS
* Vite
* REST API
* Vercel

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/LutaievMykhailo/eCommerce.git
cd eCommerce
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
